# ⚙️ Algorithms in C++

Bienvenue dans ce repository dédié aux **algorithmes fondamentaux** implémentés en **C++**.

## 🎯 Objectif

Ce projet a pour but d’implémenter les principaux **algorithmes de base** en C++ et de fournir pour chacun :

- Une **définition concise**
- Une **implémentation propre et commentée**
- Des **exemples d'utilisation**
